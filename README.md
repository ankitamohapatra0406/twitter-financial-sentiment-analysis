# Twitter Financial Sentiment Analysis 📊🐦

## 📌Project Overview
This project analyzes financial tweets to understand overall market sentiment using Natural Language Processing (NLP). Tweets are preprocessed, sentiment is predicted using a trained model, and results are visualized to uncover trends that may reflect market mood.  

The project follows an end-to-end data science workflow: data cleaning → sentiment prediction → visualization → interpretation.

## ⚙️Technologies Used
- Python
- Pandas, NumPy – Data handling
- NLTK / TextBlob / Sklearn – NLP & sentiment analysis
- Matplotlib – Data visualization
- Jupyter Notebook – Experimentation

## 📊Sentiment Distribution Visualization 
The following bar chart shows the distribution of predicted sentiments across financial tweets:
- Neutral tweets dominate the dataset
- Positive sentiment appears moderately
- Negative sentiment is comparatively lower
This suggests that most financial tweets are informational or opinion-neutral, with fewer emotionally charged reactions.

## 📈Interpretation & Insights
Markets on Twitter tend to discuss news and facts more neutrally
Positive sentiment reflects optimism around stocks or trends
Negative sentiment may signal fear, losses, or uncertainty
Such sentiment insights can be useful for:
- Market trend analysis
- Trading strategy signals
- Financial risk assessment
